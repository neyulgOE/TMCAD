# Changelog - PalletApplication (6DoF pose estimation)

## [2] Chuyen sang thiet ke stateless (khop kien truc Request-Response dong bo) + marker-style accuracy

### Boi canh
Xac nhan service native chay theo mo hinh Request-Response dong bo: moi
request (vd requestObjectDetection1203) khoi tao/huy pipeline rieng,
khong co object PalletApplication nao song xuyen suot qua nhieu request.
Client tu gui ~100 request doc lap (~8-10Hz) roi tu gom mau vao
SampleBuffer de tinh trung binh/do lech chuan.
=> Toan bo co che EMA/settle them o ban truoc (RawJumpDetector,
NormalWindowAverager, EMA vi tri/normal/yaw) khong co tac dung: moi lan
goi process() la 1 object moi, state luon rong. Da xac nhan bang thuc te
(khong co diem "muot han" nao trong chuoi mau lien tiep).

### Da bo (dead code, vo nghia trong kien truc stateless)
- Class RawJumpDetector (toan bo: checkAndUpdate, clear, isSettled,
  meanPosition, meanYaw, computeStats)
- Class NormalWindowAverager

- Member _hole1, _hole2, _normal, _yaw
- Ham smoothVector(), smoothScalar(), limitNormalJump(), limitYawJump()
- resetTemporalState() va moi cho goi no (structure_not_found branch,

- Hang so kPositionAlpha, kNormalAlpha, kMaxNormalJumpDeg,
  kNormalMedianWindow, kYawAlpha, kMaxYawJumpDeg,
  kPositionJumpStdMultiplier, kPositionJumpFloorM, kYawJumpStdMultiplier,
  kYawJumpFloorDeg, kPositionSettleStdM, kYawSettleStdDeg,
  kSettleMinSamples
- Include <deque> (khong con can)

### Da them (cai thien do chinh xac TUNG frame doc lap, port tu
marker_detection.cpp / ArucoDetector)
- `madFilterByZ()`: loc outlier theo Z bang MAD (Median Absolute
  Deviation) truoc khi dua diem vao RANSAC — port tu
  ArucoDetector::getPlaneDepthRobust
- RANSAC (ransacPlane): them buoc loai ung vien mat phang nghieng qua 60
  do so voi truc quang camera (|normal.z| < kPlaneTiltRejectCosZ = 0.5)
  ngay trong vong lap vote — port tu ArucoDetector::fitPlaneRansacZ
- Weighted least-squares refit Z = a*X + b*Y + c tren tap inlier (trong
  so Gaussian theo khoang cach toi mat phang RANSAC ban dau) — cho ra he
  so plane_a/plane_b/plane_c
- `planeDepthAtPixel()`: giao diem tia-mat phang, suy depth chinh xac tai
  BAT KY pixel 2D nao (dung cho tam bbox cua block) bang cong thuc
  Z = c / (1 - a*lx - b*ly) — thay the cho centroid cac diem sample, vi
  khong phu thuoc phan bo/mat can xung diem khi block bi khuat mot phan
  luc pallet xoay
- PlaneModel/BlockFitInfo: them field rmse_m, inlier_count, plane_a,
  plane_b, plane_c, has_plane_coeffs (rmse_m gio tinh ngay trong
  ransacPlane() de nhat quan voi tap diem da MAD-filter, tranh loi lech
  index khi fitBlockPlanes doi chieu lai voi mang diem chua loc)

### Hanh vi tinh toan (process())
- origin (x_3d/y_3d/z_3d): tinh truc tiep tu p_left_geom/p_middle_geom/
  p_right_geom cua FRAME HIEN TAI (khong con EMA/settle)
- p_left_geom/p_middle_geom/p_right_geom: uu tien planeDepthAtPixel (khi
  block co plane_a/b/c) -> fallback centroid inlier -> fallback diem tho
  tam bbox (patchDepth)
- normal (roll/pitch): dung thang planes.normal (weighted-average theo
  1/rmse cua 3 block trong CUNG 1 frame, tu fitBlockPlanes) — khong con
  median filter/jump-limit/EMA
- yaw: geometricYawDeg(p_left_geom, p_right_geom) tinh truc tiep, khong
  con jump-limit/EMA
